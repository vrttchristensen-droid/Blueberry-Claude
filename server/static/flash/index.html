Blueberry installer

Puts the right code on each board. No Arduino needed.

Before you start

  1. Use Chrome or Edge on a computer (Windows, Mac, Chromebook). iPhone/iPad and Safari can't do this.
  2. Plug the board in with a USB-C cable that carries data (not a charge-only cable).
  3. If the board doesn't appear in the list: unplug it, hold the tiny B button, plug it back in, let go, and try again. When it finishes, press the R button.

1. Button board

XIAO ESP32-S3 with the haptic driver, fuel gauge and button.

This browser can't install firmware. Open this page in Chrome or Edge on a computer. This page must be opened over https.

After installing it buzzes 3 slow pulses. On your phone, join the Wi-Fi network Blueberry-Button-Setup to finish setup.

2. Camera board

XIAO ESP32-S3 Sense with the camera and microSD card.

This browser can't install firmware. Open this page in Chrome or Edge on a computer. This page must be opened over https.

After installing, on your phone join the Wi-Fi network Blueberry-Camera-Setup to finish setup.
